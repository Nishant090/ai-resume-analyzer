# 1. Overview

AI Resume Analyzer is a web application that helps job seekers improve their resumes by analyzing uploaded PDF resumes using AI. The application provides ATS compatibility insights, identifies strengths and weaknesses, and offers actionable suggestions to increase the chances of passing recruiter and ATS screening.

---

# 2. Problem Statement

Many resumes are rejected because they are poorly structured, contain grammar issues, lack measurable achievements, or are missing relevant keywords. Users need an accessible tool that provides clear, actionable feedback before they apply for jobs.
