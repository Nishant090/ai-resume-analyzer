# User Stories

**Project:** AI Resume Analyzer  
**Version:** 1.0  
**Status:** Draft  
**Last Updated:** July 28, 2026

---

# Epic: Authentication

### US-001 Register

As a new user,
I want to create an account,
so that I can save my resume analyses.

---

### US-002 Login

As a registered user,
I want to log in securely,
so that I can access my dashboard.

---

### US-003 Logout

As a logged-in user,
I want to log out,
so that my account remains secure on shared devices.

---

# Epic: Resume Upload

### US-004 Upload Resume

As a user,
I want to upload a PDF resume,
so that it can be analyzed.

---

### US-005 File Validation

As a user,
I want the system to reject unsupported or oversized files,
so that I know my upload is valid.

---

# Epic: AI Resume Analysis

### US-006 Analyze Resume

As a user,
I want AI to analyze my resume,
so that I can improve it.

---

### US-007 ATS Score

As a user,
I want to receive an ATS compatibility score,
so that I know how well my resume may perform in applicant tracking systems.

---

### US-008 Improvement Suggestions

As a user,
I want personalized suggestions,
so that I know exactly what to improve.

---

# Epic: Dashboard

### US-009 View Analysis History

As a user,
I want to see my previous analyses,
so that I can track my progress.

---

### US-010 View Analysis Details

As a user,
I want to open a previous report,
so that I can review its feedback.

---

### US-011 Delete Analysis

As a user,
I want to delete an analysis,
so that I can keep my dashboard organized.
